# THAW Hanafuda Art

This is the 48-card Hanafuda art set imported from the `prototype/THAW`
branch of [Valithron/ante-social](https://github.com/Valithron/ante-social/tree/prototype/THAW/public/art/prototype/thaw/hanafuda).

The original 12-moons card art remains in `assets/cards/`. The default card
catalog now points to this imported set from `data/hanafuda/cards.json`.
